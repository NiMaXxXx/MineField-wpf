# Минное поле

2D-игра на **C# / WPF**. Игрок перемещается по полю, обходит мины, проходит уровни на время и попадает в таблицу лидеров. Интерфейс построен на нескольких страницах: главное меню, игра, правила, смена имени игрока и таблица лидеров.

## Возможности

- игровое поле на `Canvas` с персонажем и минами;
- прохождение уровней с таймером;
- пауза по `Esc` и экран «Вы умерли» при столкновении с миной;
- меню: «Играть», «Правила», «Лидеры», «Игрок», «Выйти»;
- ввод имени игрока и таблица лидеров с сохранением результатов;
- собственное оформление: фоны, спрайты и шрифт.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | `W` `A` `S` `D` |
| Пауза | `Esc` |

## Технологии

- **C#** — игровая логика, объектно-ориентированный подход;
- **WPF (.NET Framework 4.7.2)** — интерфейс и графика;
- **XAML** — разметка экранов;
- `Canvas` — отрисовка игрового поля;
- `DispatcherTimer` — игровой цикл и таймеры;
- навигация между страницами через `NavigationService` (классы `MainPage`, `Game`, `Liders`, `ChangeName`, `Ruler`).

## Структура проекта

```
.
├── курсач.sln              # решение Visual Studio
└── курсач/
    ├── MainWindow.xaml     # главное окно с навигацией
    ├── MainPage.xaml       # главное меню
    ├── Game.xaml(.cs)      # игровой экран и логика игры
    ├── Liders.xaml(.cs)    # таблица лидеров
    ├── ChangeName.xaml(.cs)# смена имени игрока
    ├── Ruler.xaml(.cs)     # экран правил
    ├── Properties/         # ресурсы и настройки проекта
    └── *.png, *.ico, *.otf # графика и шрифт
```

## Сборка и запуск

Проект собирается в **Visual Studio** (Windows) и требует **.NET Framework 4.7.2**.

1. открыть `курсач.sln` в Visual Studio;
2. собрать проект (`Build`);
3. запустить.
